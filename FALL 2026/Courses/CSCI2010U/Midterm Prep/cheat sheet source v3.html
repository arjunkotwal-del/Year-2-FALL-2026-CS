HOW TO ANSWER

  • Fill a blank: copy the matching template; check start, stop test, step, names.
  • Write a method: 1) what to return, 2) variable (count / sum / min), 3) loop or recursion, 4) return AFTER the loop. Test it on the example.

JAVA ESSENTIALS

  • Array: index from 0; a.length (no brackets); last = a[a.length-1]; a[a.length] crashes. int[] a = new int[5]; (all 0) or {5,2,9}. Size is fixed.
  • String: s.length(), s.charAt(i), s.substring(1) ("hello" gives "ello"), s.substring(1,3) ("el", end not included), s1.compareTo(s2) (negative = s1 first). Case matters.
  • n%10 = last digit, n/10 drops it (5072: 2 and 507). == compares, = assigns. Defaults: int 0, boolean false, object null.
  • Primitives are passed as a COPY. Arrays and objects pass a reference copy, so a method changes the SAME array (no return needed).
  • Compile error (javac refuses): missing ;, wrong type, private field used outside its class, new on an abstract class, parent object put in a child variable, abstract method not written, return null in an int method.
  • Runtime error (crashes while running): ArrayIndexOutOfBounds, StackOverflowError.
  • i % k == 0 means divisible by k. Integer division truncates: 7 / 2 = 3, 7 % 2 = 1.
  • A static method cannot use instance fields or this; an object needs new before you use it.
  • Strings are not arrays: s[i] does not compile, use s.charAt(i). += works on Strings, not arrays. An int method returns a number (or throws), never null. Out of range: arrays throw ArrayIndexOutOfBounds, the L11 list throws IndexOutOfBounds.
  • javac F.java makes F.class; java F runs public static void main(String[] args).

  • extends. Test "is a": Manager IS AN Employee, never the reverse. A subclass can add and override.

EXPLAIN WHY

  • Equal to target counts: "at least" means >=.
  • super(name) vs super.increment(): the first sets the parent's private state (first line only); the second calls the parent version of an overridden method.
  • new Person() fails: abstract, cannot be instantiated, even with a constructor.
  • Concrete class writes every abstract method: otherwise an object would have a method with no body.
  • Comparable and Arrays.sort: sort calls compareTo to decide the order. implements = many roles; extends = one parent.
  • Loop stop vs base case: both are the condition where work ends, and every step moves toward it.
  • Palindrome mismatch: one differing outer pair already proves it is not one, so return false at once.

ALGORITHMS AND BIG-O (L6 to L9)

  • Algorithm = finite, deterministic (same input, same output), effective, implementable in any language. Pseudocode is for humans. Time = count steps; space = memory; time matters most.
  • T(n) = steps for input size n. Each line costs a constant; end and comments not counted. A loop header runs ONE MORE time than its body.
  • Linear search: best (first spot) O(1), worst (missing) an+b = O(n). We use worst case: an upper-bound guarantee that happens often. Average case not covered.
  • Big-O is a notation. Worst case is a type of input. Big-O can describe either.
  • Ladder, slow to fast: 1, log n, sqrt n, n, n log n, n^2, n^3, 2^n, n!
  • Definition: f(n) = O(g(n)) if there are positive c and n0 with 0 <= f(n) <= c*g(n) for all n >= n0. g is an UPPER bound; O(g) is a SET.
  • Drop constants and small terms: 4n^2+20n+9 = O(n^2); 3+5n^2+7n^3 <= 15n^3 so O(n^3).
  • True/False rule: simplify, then LEFT = O(RIGHT) is true if left is the same or EARLIER on the ladder.

LISTS (L11)

  • Ordered = each element has a position (not sorted by value). Head = start, tail = end.
  • Interface says WHAT (add, addLast, get, isEmpty, size, toString); the implementation says HOW (ArrList uses an array).
  • size = stored now, maxSize = capacity. A bad index throws IndexOutOfBoundsException (unchecked, runtime). The slide checks index > size; the correct test is index >= size.
  • add at head = like array INSERT (shift right), O(n). addLast on a full list = shift left, O(n).
ArrList(){ this(DEFAULT_SIZE); }      // DEFAULT 10
ArrList(int capacity){ maxSize = capacity;
  size = 0; listArray = (T[]) new Object[capacity]; }
get(i): if (i<0 || i>=size)
  throw new IndexOutOfBoundsException("..");
  return listArray[i];
add(e,i) shift RIGHT (from the end):
  for (int k = size<maxSize ? size : maxSize-1;
       k > i; k--) listArray[k] = listArray[k-1];
  listArray[i] = e;  if (size<maxSize) size++;
addLast(e) when FULL, shift LEFT:
  for (int k = 1; k < listArray.length; k++)
    listArray[k-1] = listArray[k];
