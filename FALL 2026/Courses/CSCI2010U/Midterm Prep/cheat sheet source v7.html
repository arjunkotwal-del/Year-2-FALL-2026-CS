A2 JAVA ESSENTIALS

  • Array: index from 0; a.length (no brackets); last = a[a.length-1]; a[a.length] crashes. int[] a = new int[5]; (all 0) or {5,2,9}. Size is fixed.
  • String: s.length(), s.charAt(i), s.substring(1) ("hello" gives "ello"), s.substring(1,3) ("el", end not included), s1.compareTo(s2) (negative = s1 first). Case matters.
  • n%10 = last digit, n/10 drops it (5072: 2 and 507). i % k == 0 = divisible by k. 7 / 2 = 3, 7 % 2 = 1. == compares, = assigns.
  • Defaults: int 0, boolean false, objects null. An int method returns a number (or throws), never null.
  • Arrays and objects pass a reference copy, so a method changes the SAME array (no return needed). Primitives pass a copy.
  • A static method cannot use instance fields or this. Strings are not arrays: s[i] fails; += works on Strings, not arrays.

A4 REVERSE

void reverseArray(int[] a) {  // in place
  for (int i = 0, j = a.length - 1;
       i < j; i++, j--) {
    int t = a[i];
    a[i] = a[j];
    a[j] = t;
  }
}                  // {1,2,3,4} -> 4 3 2 1
String reverse(String s) {
  String out = "";
  for (int i = s.length() - 1; i >= 0; i--) {
    out += s.charAt(i);
  }
  return out;                 // "abc" -> "cba"
}

A7 BUBBLE SORT (L1, L2)

for (int i = A.length - 1; i > 0; i--) {
  for (int j = 0; j < i; j++) {
    if (A[j + 1] < A[j]) {
      int temp = A[j];        // swap
      A[j] = A[j + 1];
      A[j + 1] = temp;
    }
  }
}

i is FIXED during a pass; j moves. n elements: n-1 passes. Descending: use A[j+1] > A[j]. After pass k the last k are locked. Worst case O(n^2).

Binary search: array must be SORTED

bs(a, val, low, high):
  if (low > high) return NOT_FOUND;
  int mid = (low + high) / 2;
  if (val == a[mid]) return mid;
  else if (val < a[mid])
    return bs(a, val, low, mid - 1);
  else
    return bs(a, val, mid + 1, high);
// start bs(a, val, 0, a.length - 1)  O(log n)

a = {1,3,5,7,9,11,13}. Each step: low, high, mid = a[mid].

A9 ARRAY INSERT / DELETE (L10)

insert(a, idx, val):
  for (int i = a.length - 1; i > idx; i--) {
    a[i] = a[i - 1];          // shift RIGHT

delete(a, idx):
  for (int i = idx + 1; i < a.length; i++) {
    a[i - 1] = a[i];          // shift LEFT
  }
  a[a.length - 1] = GAP;

A12 RECURSION (L7, Lab 4)

  • Needs a base case (smallest problem, returns) and a recursive case (calls itself on a SMALLER problem). No base case = StackOverflowError.
  • Trace: go DOWN (calls wait), then back UP using the value from below. sumTo(2) means the SUM 1+2 = 3, not the number 2. Countdown n..0 = n+1 calls.
  • Print BEFORE the call = going down (3,2,1). Print AFTER = coming up (1,2,3).
sumTo, up, test, sumDigits, countDigits (answers in comments)
int sumTo(int n) {
  if (n == 0) return 0;
  return n + sumTo(n - 1);
}            // (0)=0 (1)=1 (2)=3 (3)=6
void up(int n) {              // up(3): 1 2 3
  if (n == 0) return;
  up(n - 1);
  System.out.println(n);
}
void test(int n) {   // test(2): A2 A1 B1 B2
  if (n == 0) return;
  System.out.println("A" + n);
  test(n - 1);
  System.out.println("B" + n);
}
int sumDigits(int n) {
  if (n == 0) return 0;
  return n % 10 + sumDigits(n / 10);
}            // (72) = 2 + (7 + 0) = 9
int countDigits(int n) {
  if (n < 10) return 1;
  return 1 + countDigits(n / 10);
}            // (472) = 1 + (1 + 1) = 3

String rev(String s) {
  if (s.length() <= 1) return s;
  return rev(s.substring(1))
         + s.charAt(0);
}   // "abc": rev("bc") + a
    // = (rev("c") + b) + a = "cba"
boolean isPal(String t) {
  int n = t.length();
  if (n <= 1) return true;
  if (t.charAt(0) != t.charAt(n - 1))
    return false;
  return isPal(t.substring(1, n - 1));
}   // "abba": a=a, "bb": b=b, "" true
    // "abca": a=a, "bc": b!=c false (2 calls)
int f(int n) {
  if (n <= 1) return 1;
  return f(n - 1) + f(n - 2);
}   // f(2)=2 f(3)=3 f(4)=5; 9 calls for f(4)

B1 INHERITANCE (L3, L4, Lab 2)

  • extends. Test "is a": Manager IS AN Employee, never the reverse. A subclass can add and override.
  • super(...) must be the FIRST line of the constructor (runs the parent constructor).

B3 EXPLAIN WHY

  • Equal to target counts: "at least" means >=.
  • super(name) vs super.increment(): the first sets the parent's private state (first line only); the second calls the parent version of an overridden method.
  • new Person() fails: abstract, cannot be instantiated, even with a constructor.
  • Comparable and Arrays.sort: sort calls compareTo to decide the order. implements = many roles; extends = one parent.
  • Checked vs unchecked: unchecked = extends RuntimeException (programmer error, need not be caught or declared): ArrayIndexOutOfBounds, IndexOutOfBounds, NullPointer. Checked = must be caught or declared with throws. An Error (StackOverflowError) is beyond your control.

B6 WRITE A WHOLE CLASS (Roster)

class Roster {
  private String[] names;
  private int size;
  public Roster(int capacity) {
    names = new String[capacity];
    size = 0;
  }
  public void add(String name) {
    if (size == names.length)
      throw new IndexOutOfBoundsException();
    names[size] = name;
    size++;
  }
  public String get(int index) {
    if (index < 0 || index >= size)
      throw new IndexOutOfBoundsException();
    return names[index];
  }
  public int size() { return size; }
}

B9 ALGORITHMS AND BIG-O (L6 to L9)

  • Algorithm = finite, deterministic (same input, same output), effective, implementable in any language. Pseudocode is for humans. Time = count steps; space = memory; time matters most.
  • T(n) = steps for input size n. Each line costs a constant; end and comments not counted. A loop header runs ONE MORE time than its body.
  • Linear search: best (first spot) O(1), worst (missing) an+b = O(n). We use worst case: an upper-bound guarantee that happens often.
  • Ladder, slow to fast: 1, log n, sqrt n, n, n log n, n^2, n^3, 2^n, n!
  • Definition: f(n) = O(g(n)) if there are positive c and n0 with 0 <= f(n) <= c*g(n) for all n >= n0. g is an UPPER bound; O(g) is a SET.
  • Drop constants and small terms: 4n^2+20n+9 = O(n^2); 3+5n^2+7n^3 <= 15n^3 so O(n^3).
  • True/False rule: simplify, then LEFT = O(RIGHT) is true if left is the same or EARLIER on the ladder.

B11 LISTS (L11)

  • Ordered = each element has a position (not sorted by value). Head = start, tail = end.
  • Interface says WHAT (add, addLast, get, isEmpty, size, toString); the implementation says HOW (ArrList uses an array).
  • size = stored now, maxSize = capacity. A bad index throws IndexOutOfBoundsException (unchecked, runtime). The slide checks index > size; the correct test is index >= size.
ArrList() { this(DEFAULT_SIZE); }  // 10
ArrList(int capacity) {
  maxSize = capacity;
  size = 0;
  listArray = (T[]) new Object[capacity];
}
get(i): if (i < 0 || i >= size)
    throw new IndexOutOfBoundsException();
  return listArray[i];
add(e, i): shift RIGHT from the end
  for (k = last; k > i; k--)
    listArray[k] = listArray[k - 1];
  listArray[i] = e;
  if (size < maxSize) size++;
addLast(e) when FULL: shift LEFT
  for (k = 1; k < listArray.length; k++)
    listArray[k - 1] = listArray[k];

add at head = array INSERT (shift right), O(n). addLast on a full list = shift left, O(n).
