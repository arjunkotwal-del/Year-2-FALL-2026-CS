## Overlap between the two exams (study once, use twice)

|---|---|

| Sequences, recurrences | Recursion call counts and Big-O of recursive code |

## Data Structures priority order (highest exam risk first)
1. **Recursion (L7)** — hand-trace the call stack for every example. Study Guide flags it as the #1 place students lose midterm marks.
2. **Big-O (L8–L9)** — classify code snippets, don't just memorize definitions.
3. **OOP unit (L3–L5)** — inheritance, `super`, polymorphism, abstract classes, interfaces, access modifiers. Expect code reading and short code writing.
4. **Java basics and bubble sort (L1–L2)** — traces, loop bounds, pass-by-value with references.
5. **Arrays / lists (L10–L11)** — only if lectured before Oct 25.
